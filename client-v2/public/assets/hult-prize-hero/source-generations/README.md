# Source generations archive

This directory preserves every locally persisted generated image from the Hult Prize asset-generation session, including superseded variations.

Use the organized production files outside this directory for implementation. In particular, use `09-cherry-petals-sprite-v2.png` instead of the earlier `05-cherry-petals-sprite-v1.png`.

The `reference/` directory contains the two user-provided design screenshots; it is intentionally separate from generated source art.
